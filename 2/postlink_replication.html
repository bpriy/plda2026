Introduction

This document provides the complete replication code for Section 4 (Illustrations) of the manuscript “postlink: An R Package for Post-Linkage Data Analysis”. It demonstrates a workflow of a secondary analyst using the postlink package to estimate a logistic regression model on probabilistically linked data subject to mismatch errors.

1. Preliminary Steps: Record Linkage and Paradata Preparation

The secondary analyst receives only the linked dataset, which contains the variables of primary interest for the analysis. Linkage paradata may also optionally be supplied. Information on the underlying record linkage process may be limited and the individual files which were linked are not accessible.

Here, we load the LD1000 dataset included in the postlink package.

2. The Benchmarks (Models 1-3)

We first establish three standard benchmark models that do not use postlink. The primary objective is to estimate the following logistic regression model:

formula_sci <- Disease_Status ~ BMI + Age + Treatment

  • Oracle: The unobservable gold standard, fit on the truly matched records.

  • Naive (All Links): A standard logistic regression that ignores the presence of mismatches.

  • Naive (Safe Matches): A model restricted only to high-confidence “safe matches”, discarding all uncertain records.

# 1. Oracle: Fit on the true, perfectly linked data
fit_oracle <- glm(True_Disease_Status ~ BMI + Age + Treatment, 
                  data = LD1000, family = "binomial")

# 2. Naive: Fit on all linked data, ignoring potential mismatch error
fit_naive <- glm(formula_sci, 
                 data = LD1000, 
                 family = "binomial")

# 3. Naive (Safe Matches): Fit only on the safe matches
fit_naive_safe <- glm(formula_sci, 
                      data = subset(LD1000, safe_match == TRUE), 
                      family = "binomial")

5. Prior Knowledge (Model 9)

The Bayesian mixture framework (adjMixBayes()) allows the analyst to integrate historical data or domain expertise via prior distributions.

round(qlogis(mean(LD1000$Disease_Status)), 2)
## [1] -1.09
# Phase 1: Define Informative Priors
adj_bayes <- adjMixBayes(
  linked.data = LD1000, 
  priors = list(
    intercept2 = "normal(-1.09, 3)", 
    # Empirical log-odds of outcome prevalence
    beta2 = "normal(0, 0.01)",       
    # Assume Y and X are roughly independent among non-links
    theta = "beta(70, 30)"           
    # A priori expectation of a ~70% correct match rate
  )
)
print(adj_bayes)

Decoupling Linkage and Analysis via Multiple Imputation

Once the Bayesian model is fitted, the multiple imputation generic mi_with() can be used to explore alternative models of interest without rerunning the MCMC sampler.

# Define an alternative exploratory model (e.g., marginal effect of Treatment)
formula_alternative <- Disease_Status ~ Treatment

# Pool the new model using the pre-computed linkage posteriors
pooled_mi_fit <- mi_with(
  object = fit_bayes, 
  data = LD1000, 
  formula = formula_alternative, 
  family = binomial()
)
print(pooled_mi_fit)

6. Results Extraction and Visualization

We gather the coefficients and standard errors across all eight models to generate the comparative table and figure presented in the manuscript.

extract_model <- function(model_name, fit) {
  terms <- c("(Intercept)", "BMI", "Age", "Treatment")
  
  if (inherits(fit, "glmELE")) {
    est <- fit$coefficients["BLUE", terms]
    var_diag <- diag(fit$var[["BLUE"]])
    if (is.null(names(var_diag))) names(var_diag) <- colnames(fit$coefficients)
    se <- sqrt(var_diag)[terms]
  } else if (inherits(fit, "glmMixBayes")) {
    est <- colMeans(fit$estimates$coefficients)[terms]
    se <- apply(fit$estimates$coefficients, 2, sd)[terms]
  } else {
    sum_obj <- summary(fit)$coefficients
    est <- sum_obj[terms, 1]
    se <- sum_obj[terms, 2]
  }
  
  data.frame(Model = model_name, Term = terms, 
             Estimate = as.numeric(est), SE = as.numeric(se))
}

# Compile results list
res_list <- list(
  extract_model("1. Oracle", fit_oracle),
  extract_model("2. Naive (All Links)", fit_naive),
  extract_model("3. Naive (Safe Matches Only)", fit_naive_safe),
  extract_model("4. ELE (Audit Sample)", fit_ele_audit),
  extract_model("5. EM (Global Rate)", fit_em_rate),
  extract_model("6. EM (Safe Matches Only)", fit_em_safe),
  extract_model("7. EM (Posterior Probabilities)", fit_em_prob),
  extract_model("8. EM (All)", fit_em_all),
  extract_model("9. Bayesian (Informative Priors)", fit_bayes)
)

plot_data <- bind_rows(res_list) %>%
  mutate(Conf.Low = Estimate - 1.96 * SE, 
         Conf.High = Estimate + 1.96 * SE,
         Model = factor(Model, levels = rev(unique(Model))))
